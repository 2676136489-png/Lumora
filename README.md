# Lumora 区块插件库

197 个可复用设计区块，按 22 个分类整理。每个区块提供实时预览、完整源码与中文提示词，支持一键复制。原生 HTML、CSS 与 JavaScript 实现，无构建步骤，字体、图片与视频全部本地存放。

在线预览：**https://wbapp-v2ojc8qetmpj74ypnddj2s.app.workbuddy.host/?sharecode=32KDFEZKHH**

## 1. 项目背景

前端开发在搭建页面时，重复劳动集中在头部导航、表单、卡片、通知与空状态等通用区块。现成组件库通常绑定特定框架与构建链，难以直接嵌入原生项目；素材站点的代码片段又往往缺少上下文与说明。

Lumora 将区块以「可独立运行的 HTML 文档」形式交付：源码内联结构、样式与交互，基础设计令牌完整，复制后即可使用，不依赖框架、构建工具或外部资源。

## 3. 问题定义

| 问题 | 现状 | 目标 |
| --- | --- | --- |
| 组件绑定框架 | 组件库依赖 React / Vue 与构建链 | 区块为原生 HTML / CSS / JS，可直接运行 |
| 代码缺少说明 | 片段无提示词与设计意图 | 每个区块附带中文提示词与分类标签 |
| 视觉体系分散 | 拼接后风格割裂 | 提供四套主题，统一令牌与圆角、间距规范 |
| 检索效率低 | 按文件堆积，难以查找 | 22 个分类 + 关键词搜索，详情面板即时预览 |

- 中文提示词，说明界面构成与交互意图。
- 一键复制源码与提示词。

## 5. 区块数据结构

`data/` 下每个文件向 `window.PLUGINS` 追加数组，单项结构如下：

```js
{
  id: "file-drop",        // 唯一标识
  name: "文件拖放",        // 区块名称
  cat: "forms",           // 所属分类
  desc: "拖拽上传区域与文件列表，支持点击选择。",
  tags: ["表单", "上传", "拖放", "文件"],
  prompt: "…",            // 中文提示词
  html: "…",              // 结构
  css: "…",               // 样式
  js: "…"                 // 交互，可为空
}
```

复制源码后可直接作为独立页面运行。

## 6. 主题与演示

- 外层提供四套主题，切换时统一作用于全部区块。
- 附一套 Wiki 模板（19 个页面），演示整套区块替换内容后的效果，同时作为独立站点使用。
- 首页采用全屏视频与液态玻璃视觉，作为区块库入口。

## 7. 技术实现

| 项 | 说明 |
| --- | --- |
| 页面技术 | 原生 HTML、CSS、JavaScript |
| 数据组织 | `data/` 按分类拆分，页面运行时合并 |
| 样式分层 | `lumora.css` 负责首屏视觉，`library.css` 负责区块库列表与详情 |
| 交互 | `library.js` 实现筛选、搜索、复制与预览 |
| 外部依赖 | 无，字体、图片、视频均为本地文件 |
